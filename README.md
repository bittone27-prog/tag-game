# TAG

Jeu de chat 2 à 4 joueurs sur le même écran.

## Déploiement Render
- Type : Web Service
- Build Command : (vide)
- Start Command : `npm start`

## Contrôles
- J1 (rouge) : Q / D pour bouger, Z pour sauter
- J2 (jaune) : flèches gauche/droite, flèche haut pour sauter
- J3 (vert) : J / L, I pour sauter
- J4 (bleu) : 4 / 6 (pavé num.), 8 pour sauter
