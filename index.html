// PROTOCOLE

Règles & contrôles

01 / BUT

Ne sois pas chat

Le chat accumule du temps. À la fin des 60 secondes, le joueur avec le moins de temps gagne.

02 / TRANSFERT

Touche pour passer

Quand le chat touche un joueur, le rôle change. Un court délai d'immunité évite les rebonds instantanés.

03 / PLATEFORMES

Saute !

Utilise les plateformes pour fuir ou pour rattraper. Les bords de l'écran sont reliés.
